# 🏦 Replit Prompt: Ashish Finance Services Website

---

## PROJECT OVERVIEW

Build a **premium 5-page financial services website** for **Ashish Finance Services** owned by Mr. Ashish Vilas Urkude. The website should feel **luxury, trustworthy and authoritative** — like a high-end wealth management firm. The language mix is **English + Marathi** (Marathi used for taglines, section subheadings, trust lines, and emotional appeal phrases).

---

## TECH STACK

- **HTML5 + CSS3 + Vanilla JavaScript** (no frameworks needed)
- All pages in separate HTML files
- Shared `style.css` and `script.js`
- Google Fonts for typography
- No backend required — purely static site
- Mobile responsive (works on all screen sizes)

---

## THEME & DESIGN SYSTEM

### Color Palette
```
--gold-primary: #C9A84C
--gold-light: #E8C96D
--gold-dark: #A0823A
--black-deep: #0A0A0A
--black-card: #111111
--black-surface: #1A1A1A
--white-text: #F5F5F0
--white-muted: #BBBBAA
--gold-gradient: linear-gradient(135deg, #C9A84C, #E8C96D, #A0823A)
```

### Typography
- **Display / Headings**: `Playfair Display` (Google Fonts) — elegant serif
- **Body text**: `DM Sans` (Google Fonts) — modern, readable
- **Marathi text**: Use `Noto Sans Devanagari` (Google Fonts)

### Design Style
- Dark background (#0A0A0A) with gold accents
- Cards with subtle gold borders and dark surfaces
- Gold shimmer/glow effects on hover
- Thin gold horizontal divider lines between sections
- Subtle diagonal or radial gold gradient overlays in hero section
- Premium drop shadows using gold tones: `box-shadow: 0 4px 30px rgba(201,168,76,0.15)`
- Smooth scroll behavior
- Fade-in animations on scroll (Intersection Observer API)

## ANIMATIONS & INTERACTIONS

1. **Fade-in on scroll**: All section cards use `IntersectionObserver` — slide up + fade in
2. **Counter animation**: Stats (1000+, 500+, 6+) count up when section enters viewport
3. **Navbar**: Shrinks slightly on scroll, gains stronger gold border
4. **Hover effects**: Cards lift with `translateY(-4px)` + gold glow shadow
5. **Gold shimmer**: Apply a subtle shimmer sweep animation on the hero headline text
6. **Page transitions**: Smooth fade between pages using CSS transitions
